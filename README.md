# NailDesigner
Projeto Front-End de uma landing page desenvolvida para a nail designer Thalita Pivato, com foco em UX/UI Design e responsividade.

O projeto foi desenvolvido para apresentar os serviços da profissional de forma visual, intuitiva e adaptada para diferentes dispositivos.

🛠️ Tecnologias
- HTML5
- CSS3
